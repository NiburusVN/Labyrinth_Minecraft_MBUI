**Projet A31 `Je suis perdu (Labyrinth - le jeu de société)`**
==========================================================

Ce projet consiste à recréer le jeu de société **Labyrinth** en utilisant le language *Java*.
Afin de pouvoir tester le projet, assurez vous d'avoir un IDE compatible avec *Java*.

Notre projet utilise des graphismes inspirés de *Minecraft*.

GUIDE D'INSTALLATION
--------------------

### Pour l'installation:

- `Forkez` le projet
- `Clonnez` le projet sur votre appareil à l'aide de git

##### OU

- copiez le code sources, vous aurez besoin des dossiers:
    + `Labyrinth`
    + `img`
    + `helpers`

Ces dossiers contiennent respectivement *le jeu*, *les images*, et une classe fourni par `M.Adrien K.` qui permet de *supperposer des images*.

### Pour la compilation:

Tout est normalement prêt dans la classe **Main.java** présent le dossier `Labyrinth`.
Compilez le fichier avec votre IDE.

> ***Note:** Notre projet utilise Java Swing afin d'avoir une interface graphique. assurez vous de pouvoir importer `javax.swing.*`*

Malheureusement, il n'y a pas de fichier executable qui permet de compiler directement le projet sans difficulté.
